KEY CLINICAL INSIGHTS
=====================
1. SUICIDAL IDEATION (R45.851) is the single most common diagnosis:
   - 2,968 occurrences (29.2% readmission rate)
   - Documented in NSSI column indicating self-injury context
   
2. NEURODEVELOPMENTAL DISORDERS are highly represented:
   - ADHD: 2,333 occurrences (18.4% readmission rate)
   - Autism Spectrum Disorder: 794 occurrences (19.9% readmission rate)
   - Conduct Disorder: 696 occurrences (19.8% readmission rate)
   
3. INTERNALIZING DISORDERS prevalent:
   - Depressive Disorders: 3,182 occurrences (20.2% readmission rate)
   - Anxiety Disorders: 1,980 occurrences (18.5% readmission rate)
   - PTSD/Trauma-Related: 2,572 occurrences (19.7% readmission rate)

4. HIGH-RISK DIAGNOSTIC GROUPS (>25% readmission rate):
   - Neurocognitive Disorders (33.3%)
   - Non-Suicidal Self-Injury Behavior (29.2%)
   - Other Neurodevelopmental Disorders (27.7%)
   - Mental Disorders Due to Medical Condition (27.3%)

DELIVERABLES CREATED
====================
1. ICD10_to_DSM5_Reference.csv
   Complete mapping of all 1,863 ICD-10 codes in dataset to:
   - Diagnosis name
   - ICD-10 category
   - DSM-5 TR category (where applicable)
   - DSM-5 code
   - Frequency in dataset

2. DSM5_Category_Summary.csv
   Prevalence statistics for 31 DSM-5 diagnostic categories
   - Unique patients per category
   - Total occurrences
   - Useful for epidemiologic analysis

3. DSM5_Readmission_Analysis.csv
   Risk stratification by psychiatric diagnosis
   - Readmitted counts and rates
   - Identifies high-risk diagnostic groups
   - Actionable for clinical intervention prioritization

4. annotated_psychiatric_data.csv
   Original dataset enhanced with:
   - Diagnosis names for all three ICD columns
   - DSM-5 category assignments
   - DSM-5 mapping counts
   - Ready for multivariate analysis

5. diagnoses_long_form.csv
   27,884 diagnosis records for granular analysis:
   - One row per diagnosis per patient
   - Includes diagnosis type (Visit/NSSI/Chronic)
   - DSM-5 category for systematic grouping
   - Ideal for trend analysis and ML applications
